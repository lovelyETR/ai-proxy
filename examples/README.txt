  强烈建议的写法：让模型输出极简格式
  ────────────────────────────────────────────────────────────────────────────
  引擎受限的插件里解析 JSON 很痛苦。所以在 system 提示里要求：

      「回答必须只有一行，格式：YES|理由。理由不超过 30 字。」

  然后直接按 | 切两半就行，不用引任何 JSON 库：

      Python :  verdict, reason = ans.split("|", 1)
      C#     :  var p = ans.Split(new[]{'|'}, 2);
      Lua    :  local v, r = ans:match("^([^|]+)|(.+)$")
      Java   :  String[] p = ans.split("\\|", 2);
      Pawn   :  SplitString(ans, "|", parts, sizeof(parts))

  这一招在 6 个示例文件里全都用了。
