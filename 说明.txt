【这是什么】

  一个跑在你本机的小服务。作用是：让「任何需要调用 AI 的插件」
  都能通过它连上 AI，而真实的 API Key 只留在这一处。

  ★ 它是【引擎无关】的。

  它就是一个标准 HTTP 服务，说的是 OpenAI 兼容格式。
  所以「适配某个引擎」不需要为那个引擎改任何东西 ——
  只要那个引擎的插件「会发 HTTP 请求」就能接。

  已经覆盖（每个都有可复制的代码，见 接入指南.txt 和 示例代码\）：

      Unity 引擎        BepInEx / MelonLoader / RimWorld / 单机模组
      起源引擎          SourceMod / VScript / Lua
      虚幻引擎          C++ / 蓝图(VaRest)
      寒霜引擎          Venice Unleashed / RCON + 外部程序
      GMod / FiveM      Lua
      Minecraft         Forge / Fabric / Bukkit / Spigot / Paper
      Godot             GDScript / C#
      CryEngine         Lua
      GameMaker         GML
      GoldSource        AMX Mod X
      其他              通用 HTTP 契约（Python / Node / curl / C）

【为什么需要它】

  直接让每个插件各存一份 API Key，有三个麻烦：

    1. Key 散落在各处配置文件里，一旦哪个被分享出去就泄露了
    2. 插件逻辑写错可能疯狂发请求，刷爆你的余额
    3. 想换 Key 或者换模型，得把所有插件挨个改一遍

  用代理之后：

    Key 只在代理这一处      →  插件里全是可随时吊销的令牌
    统一限流、每日配额      →  插件写错也刷不爆
    换 Key / 换模型只改这里 →  所有插件自动生效
    分账清楚               →  /stats 里能看到每个令牌用了多少


【怎么用 —— 三步】

  第一步：编辑配置

     用记事本打开「启动接口.bat」，最上面那段就是要改的：

         set AI_API_KEY=sk-在这里填你的Key
         set AI_TOKENS=my-token-1:我的服务器

     AI_TOKENS 是允许使用这个接口的令牌。
     格式是  令牌:标签，多个用逗号隔开。
     标签只是给你自己看的，方便分账。

     不知道填什么令牌？双击「生成令牌.bat」拿一个随机的。


  第二步：启动

     双击「启动接口.bat」

     看到这样的输出就成功了：

         ================================================================
            AWA :: 通用 AI 接口代理
         ================================================================
            监听     : 127.0.0.1:8787
            上游     : https://api.deepseek.com
         ...

     这个窗口要一直开着。关掉它接口就停了。


  第三步：让插件接过来

     在任何插件的配置里，把 API 地址改成这个代理：

         api_base_url:  http://127.0.0.1:8787/v1
         api_key:       my-token-1          ← 填令牌，不是真 Key

     别的什么都不用改 —— 因为它就是 OpenAI 兼容接口。


【拿 AWA 反作弊插件举例】

     原来（直连官方，配置里存真 Key）：

         api_base_url: 'https://api.deepseek.com'
         api_key: 'sk-你的真Key'

     改成（走代理，配置里只有令牌）：

         api_base_url: 'http://127.0.0.1:8787/v1'
         api_key: 'my-token-1'

     如果你要把插件发给别人，就用这个方式 ——
     对方拿到的是令牌，你随时可以在 AI_TOKENS 里删掉它。


【配置项一览】

     AI_API_KEY          上游 API Key（必填）
     AI_TOKENS           允许的令牌，格式 令牌:标签，逗号分隔（必填）
     AI_HOST             监听地址，默认 127.0.0.1
     AI_PORT             监听端口，默认 8787
     AI_UPSTREAM         上游地址，默认 https://api.deepseek.com
     AI_MODEL            强制使用的模型，留空则透传调用方指定的
     AI_RATE_PER_MIN     每个令牌每分钟最多几次请求，默认 30
     AI_DAILY_QUOTA      每个令牌每天最多几次请求，默认 500
     AI_TIMEOUT          上游超时秒数，默认 30
     AI_ADMIN_TOKEN      管理令牌，用于访问 /stats

  ★ 换成别的 OpenAI 兼容服务（本地 Ollama、LM Studio、自建中转等）
    只需要改 AI_UPSTREAM 和 AI_MODEL。


【接口一览】

     POST /v1/chat/completions     OpenAI 兼容，插件用这个
     GET  /health                  探活（不需要令牌）
     GET  /stats                   用量统计（需要管理令牌）

  探活：

     curl http://127.0.0.1:8787/health

  看用量：

     curl -H "Authorization: Bearer local-admin" http://127.0.0.1:8787/stats


【常见问题】

  Q: 启动就报「未配置 AI_API_KEY」
  A: 启动接口.bat 里的 AI_API_KEY 还是占位符，填上你自己的。

  Q: 插件报 401
  A: 插件里的 api_key 填错了。要填 AI_TOKENS 里那个令牌，不是真 Key。

  Q: 插件报 429
  A: 触发限流了。把 AI_RATE_PER_MIN 或 AI_DAILY_QUOTA 调大。

  Q: 关掉窗口插件就不能用了？
  A: 对。这个代理要一直开着。想让它后台常驻，
     可以用 任务计划程序 开机自启，或者做成 Windows 服务。

  Q: 真 Key 会不会被插件拿到？
  A: 不会。Key 只在代理进程的内存里，插件只拿到令牌。
     上游请求由代理代发。

  Q: 能不能只让本机访问？
  A: AI_HOST 默认就是 127.0.0.1，只有本机能连。
     除非你确实要跨机器用，否则不要改成 0.0.0.0。
